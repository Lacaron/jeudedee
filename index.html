Comment jouer

🎯
Objectif

Marquez plus de points que votre adversaire en remplissant votre grille 3×3.

🎲
Tour de jeu

Un dé est lancé automatiquement. Choisissez une colonne pour y placer votre dé.

✖️
Multiplication

Des dés identiques dans la même colonne se multiplient !

2 dés pareils → valeur × 2 3 dés pareils → valeur × 3

Exemple : colonne [4, 4, 2]
→ 4×2 + 4×2 + 2×1 = 18 pts

💥
Destruction

Placer un dé détruit tous les dés identiques dans la colonne alignée de l'adversaire.

🏆
Fin de partie

La partie se termine quand un plateau est plein. Le joueur avec le score total le plus élevé gagne.

🤖
Difficultés du bot
Facile Choisit une colonne au hasard.
Moyen Favorise les combos et cherche à détruire vos dés.
Difficile Calcule le coup optimal : maximise son gain et votre perte de points.
